# Portfolio

Personal portfolio of Luciano Nicolini, focused on mobile development, web products and creative engineering.

The visual direction is editorial neo-brutalism inspired by [StitchHub](https://github.com/luchonicolini/StitchHub), adapted to a personal portfolio rather than a community platform.

## Status

Planning and design foundation. No application scaffold or production deployment yet.
