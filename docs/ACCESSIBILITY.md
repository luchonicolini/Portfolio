# Accessibility

Target WCAG 2.2 AA. Use semantic landmarks, logical heading order, descriptive links, meaningful alt text and decorative SVG hidden from assistive technology. Provide a skip link, visible focus, keyboard navigation, correct language attributes and accessible mobile navigation.

Verify text contrast (4.5:1 normal, 3:1 large), meaningful non-text contrast and target dimensions (WCAG minimum 24 CSS px with applicable exceptions; aim for 44px). Do not rely on color alone. Support 320px viewport and zoom/reflow without horizontal overflow except intrinsically scrollable content.

Respect reduced motion and offer pause controls for persistent moving content. Use accessible names and status announcements when needed. Test with axe-core, keyboard and representative screen reader checks. Automated scans are not proof of conformance. Record unresolved issues explicitly.
